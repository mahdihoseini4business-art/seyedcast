یک افزونه حرفه‌ای مدیریت پادکست با پلیر سفارشی و رابط کاربری زیبا

== Description ==

SeyedCast یک افزونه کامل برای مدیریت پادکست در وردپرس است. با استفاده از این افزونه می‌توانید:

* اپیزودهای پادکست را مدیریت کنید
* پلیر صوتی سفارشی و زیبا داشته باشید
* دسته‌بندی و تگ برای اپیزودها ایجاد کنید
* آمار پخش و دانلود را رصد کنید
* صفحه پادکست شبیه Spotify و Castbox داشته باشید

=== ویژگی‌ها ===

* پست تایپ سفارشی اپیزود
* پلیر صوتی حرفه‌ای شبیه Spotify
* دسته‌بندی و تگ
* جستجو و فیلتر
* آمار پخش و دانلود
* تنظیمات سئو
* ریسپانسیو و RTL
* پشتیبانی از فارسی

=== شورتکد ===

`[seyedcast]`

پارامترها:
* style: grid | list (پیش‌فرض: grid)
* posts_per_page: تعداد اپیزودها (پیش‌فرض: 12)
* category: دسته‌بندی خاص
* tag: تگ خاص
* orderby: date | title | episode_number
* order: ASC | DESC

== Installation ==

1. فایل افزونه را در پوشه wp-content/plugins آپلود کنید
2. افزونه را از صفحه افزونه‌ها فعال کنید
3. از منوی پادکست > تنظیمات، تنظیمات دلخواه را اعمال کنید
4. با شورتکد [seyedcast] صفحه پادکست را ایجاد کنید
