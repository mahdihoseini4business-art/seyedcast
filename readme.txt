پادکست آموزشی با چند شو/سری، صفحه آرشیو و سینگل سئو‌محور، پلیر ثابت، تم‌های طراحی و نصب PWA.

== Description ==

Seyedcast یک افزونه وردپرس برای انتشار پادکست‌های آموزشی است:

* چند شو/سری جدا با اپیزودهای مستقل
* صفحات آرشیو، شو و اپیزود با URLهای سئو‌پسند
* تم‌های شبیه Spotify، Castbox، Apple Podcasts، YouTube Music و SoundCloud
* تنظیم رنگ‌بندی از پنل
* نوار پخش ثابت پایین صفحه
* پشتیبانی PWA و پیشنهاد افزودن به هوم‌اسکرین
* toast «پادکست جدید اومد» برای کاربران نصب‌شده روی Home Screen
* دکمه «خبرم کن» برای ثبت نام و شماره علاقه‌مندان
* دکمه «انتشار پادکست» برای کپی/اشتراک لینک
* نوار پیشرفت شنیدن، مرتب‌سازی اپیزودها و اسکلتون هنگام جابه‌جایی صفحات

== Installation ==

1. پوشه `seyedcast` را در `wp-content/plugins` کپی کنید.
2. افزونه را از منوی افزونه‌ها فعال کنید.
3. از منوی Seyedcast تنظیمات را انجام دهید و شو/اپیزود بسازید.
